# Annotateshot Support

Annotateshot의 공개 지원 공간입니다. 버그 신고, 기능 제안, 사용 질문을 남겨 주세요.

Public support for Annotateshot — report bugs, suggest features, and ask questions.

[Mac App Store](https://apps.apple.com/app/annotateshot/id6790591845?mt=12) · [사용 안내 / User guide](docs/guide.md) · [지원 웹사이트 / Support website](https://annotateshot.com/mac/support)

## 문의하기 · Get help

| 하고 싶은 일 / What you need | 링크 / Link |
| --- | --- |
| 버그 신고 / Report a bug | [버그 신고 양식 / Bug report](https://github.com/tiger-dreams/Annotateshot-support/issues/new?template=bug_report.yml) |
| 기능 제안 / Suggest a feature | [기능 제안 양식 / Feature request](https://github.com/tiger-dreams/Annotateshot-support/issues/new?template=feature_request.yml) |

한국어와 영어 모두 환영합니다. 먼저 비슷한 이슈가 있는지 검색해 주세요. 있다면 기존 이슈에 재현 정보나 의견을 덧붙여 주세요.

Korean and English are welcome. Search existing issues first; if someone has reported the same problem, add your details there.

## 공개 범위 · What is public

이곳의 이슈, 댓글, 첨부 파일은 누구나 볼 수 있습니다. 스크린샷을 올리기 전에 이름, 이메일, 결제 정보, 개인 문서 등 민감한 내용을 가려 주세요. 영수증, 인증 키, 비밀번호 또는 원본 개인정보를 올리지 마세요.

Issues, comments, and attachments are public. Redact personal or sensitive information before attaching screenshots. Do not post receipts, credentials, passwords, or private documents.

결제·환불 등 개인정보가 필요한 문의는 [지원 웹사이트](https://annotateshot.com/mac/support)를 이용해 주세요. App Store 환불은 [Apple 환불 요청](https://reportaproblem.apple.com/)에서 신청할 수 있습니다.

For requests involving private information, use the [support website](https://annotateshot.com/mac/support). Request App Store refunds through [Apple](https://reportaproblem.apple.com/).

## 이 저장소에 관하여 · About this repository

이 저장소는 지원 문서와 사용자 피드백을 위한 공간입니다. 앱 소스 코드는 포함하지 않습니다. 기능 제안이 등록되었다고 구현이나 출시 일정이 확정되는 것은 아닙니다.

This repository contains support documentation and user feedback. It does not contain the app source code. A feature request does not guarantee implementation or a release date.
