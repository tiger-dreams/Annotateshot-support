# 피드백 안내 · Feedback guidelines

- 먼저 비슷한 이슈를 검색해 주세요. / Search for an existing issue first.
- 하나의 이슈에는 하나의 문제나 제안을 적어 주세요. / Keep each issue focused on one problem or suggestion.
- 재현 방법과 기대한 동작을 구체적으로 설명해 주세요. / Describe reproduction steps and expected behavior clearly.
- 개인정보를 가린 뒤 이미지를 첨부해 주세요. / Redact private information before attaching images.
- 서로 존중하는 표현을 사용해 주세요. / Be respectful when discussing feedback.

`bug`, `enhancement`, `question`은 문의 유형입니다. 새 문의에는 `needs-triage`가 붙습니다. 관리자는 필요에 따라 `investigating`, `planned`, `released` 상태를 표시할 수 있습니다. `planned`는 출시일을 약속하지 않습니다.

`bug`, `enhancement`, and `question` describe the type of request. New reports receive `needs-triage`. Maintainers may use `investigating`, `planned`, or `released` to indicate progress. `planned` does not promise a release date.

앱 소스 코드는 이 저장소에서 관리하지 않습니다. 문서 개선은 Pull Request로 제안할 수 있습니다.

The app source is not maintained here. Documentation improvements are welcome through pull requests.
