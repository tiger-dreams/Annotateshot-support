GitHub 이슈, 댓글, 첨부 파일은 공개됩니다. 이름, 이메일, 개인 문서와 결제 정보를 가려 주세요. 이슈를 작성하려면 GitHub 계정이 필요합니다.

개인정보가 필요한 문의는 지원 웹사이트를 이용해 주세요. App Store 환불은 Apple에 요청할 수 있습니다.

[비공개 지원](https://annotateshot.com/mac/support) · [App Store 환불 요청](https://reportaproblem.apple.com/)

## 이 저장소에 관하여

지원 문서와 사용자 피드백을 위한 저장소이며 앱 소스 코드는 포함하지 않습니다. 기능 제안은 구현이나 출시일을 보장하지 않습니다.

[앱 개인정보 처리방침 보기](https://annotateshot.com/mac/privacy)
