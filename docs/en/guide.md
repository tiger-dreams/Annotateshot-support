# User guide

From your first capture to a useful bug report.

1. **Install and launch** — Install Annotateshot from the Mac App Store and launch it.

2. **Capture or open an image** — Use the Annotateshot icon in the macOS menu bar to capture a screenshot or open an image.

3. **Add annotations** — Choose an editor tool, such as shapes, text, highlighting, or mosaic. Available options may vary by app version.

4. **Save or copy** — Save the edited image or copy it for sharing. Check that sensitive information is hidden before sharing.

## Screen recording permission

In System Settings → Privacy & Security, allow Annotateshot to record the screen. Quit and relaunch after changing the permission. If capture still fails, report a bug with your macOS and app versions.

## Help us reproduce the problem

- App version and build number
- macOS version
- The steps that trigger the problem
- Expected result and actual result
- A screenshot or recording with private information redacted

GitHub issues, comments, and attachments are public. Redact names, email addresses, private documents, and payment details. A GitHub account is required to post an issue.
