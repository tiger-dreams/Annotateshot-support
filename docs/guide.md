# 사용 안내 · User guide

Annotateshot은 macOS에서 화면을 캡처하고 이미지에 주석을 넣는 앱입니다. macOS 14 이상에서 사용할 수 있습니다.

Annotateshot captures screenshots and annotates images on macOS. It requires macOS 14 or later.

## 시작하기 · Getting started

1. [Mac App Store](https://apps.apple.com/app/annotateshot/id6790591845?mt=12)에서 앱을 설치하고 실행합니다.
2. 메뉴 막대의 Annotateshot 아이콘에서 캡처하거나 이미지를 엽니다.
3. 편집 창에서 필요한 주석 도구를 선택합니다.
4. 편집한 이미지를 저장하거나 복사합니다.

1. Install and launch the app from the [Mac App Store](https://apps.apple.com/app/annotateshot/id6790591845?mt=12).
2. Use the Annotateshot menu bar icon to capture a screenshot or open an image.
3. Select an annotation tool in the editor.
4. Save or copy the edited image.

## 캡처가 되지 않을 때 · Capture permission

macOS 시스템 설정 → 개인정보 보호 및 보안에서 Annotateshot의 화면 기록 권한을 확인해 주세요. macOS 버전에 따라 항목 이름이 다를 수 있습니다. 권한을 변경한 뒤에는 앱을 종료하고 다시 실행해 주세요.

Check Annotateshot's screen recording permission in System Settings → Privacy & Security. The exact label may vary by macOS version. Quit and relaunch the app after changing permission.

계속 문제가 생기면 앱 버전, macOS 버전, 재현 단계를 포함해 [버그를 신고](https://github.com/tiger-dreams/Annotateshot-support/issues/new?template=bug_report.yml)해 주세요.

If the issue continues, [report a bug](https://github.com/tiger-dreams/Annotateshot-support/issues/new?template=bug_report.yml) with the app version, macOS version, and steps to reproduce it.

## 문의에 도움이 되는 정보 · Useful report details

- 앱 버전과 빌드 번호 / App version and build number
- macOS 버전 / macOS version

- 기대한 결과와 실제 결과 / Expected and actual results
- 개인정보를 가린 스크린샷 또는 짧은 영상 / A redacted screenshot or short recording

결제 영수증이나 개인정보는 공개 이슈에 올리지 마세요. 관련 문의는 [지원 웹사이트](https://annotateshot.com/mac/support)를 이용해 주세요.

Do not post receipts or personal information in public issues. Use the [support website](https://annotateshot.com/mac/support) for those requests.
