# 사용 안내

첫 캡처부터 문제를 전달하는 방법까지.

1. **설치하고 실행하기** — Mac App Store에서 Annotateshot을 설치하고 실행합니다.

2. **캡처하거나 이미지 열기** — macOS 메뉴 막대의 Annotateshot 아이콘에서 화면을 캡처하거나 이미지를 엽니다.

3. **주석 추가하기** — 편집 창에서 도형, 텍스트, 강조, 모자이크 등의 도구를 선택합니다. 앱 버전에 따라 제공되는 옵션이 다를 수 있습니다.

4. **저장하거나 복사하기** — 편집한 이미지를 저장하거나 복사합니다. 공유하기 전에 민감한 정보가 가려졌는지 확인해 주세요.

## 화면 기록 권한

시스템 설정 → 개인정보 보호 및 보안에서 Annotateshot의 화면 기록을 허용해 주세요. 권한을 변경한 뒤 앱을 종료하고 다시 실행하세요. 계속 캡처가 안 된다면 macOS와 앱 버전을 포함해 버그를 신고해 주세요.

## 문제 재현에 도움이 되는 정보

- 앱 버전과 빌드 번호
- macOS 버전
- 문제가 발생하는 작업 순서
- 기대한 결과와 실제 결과
- 개인정보를 가린 스크린샷이나 영상
